    Причины

      События

        Доступность считается по попыткам: окно без самопроверки и без трафика своих клиентов — «нет данных», а не сбой. На сервере хранятся только числа, классы соединений и место поломки, без адресов. Окна — 31 день, итоги суток — год. Выключить и стереть: sudo xm health off.

        Панель остановлена

        Порт на сервере закрыт, ссылка с токеном больше не действует. Чтобы открыть панель снова, на сервере:

        sudo xm ui

        Токен каждый раз новый: открыть нужно ссылку, которую напечатает команда.
