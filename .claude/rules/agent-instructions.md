# Правки скиллов и правил

## Что где живёт

- `AGENTS.md` — верное в каждой сессии: факты проекта и правила «всегда», до 200 строк;
  процедуры — не сюда. `CLAUDE.md` — только `@AGENTS.md` и особенности Claude Code.
- `.claude/rules/*.md` — правила, нужные при работе с определёнными файлами; во фронтматтере
  только `paths`.
- Скилл — процедура или экспертиза, грузится по описанию. `SKILL.md` — обзор, порядок работы
  и указатели (около 200 строк, жёсткий предел 500); подробности — в `references/`, ссылки на
  них — только из `SKILL.md`, без цепочек.
- `.claude/HANDOFF.md` — с чего продолжать: открытые вопросы, снятые гипотезы, долг; до 150
  строк. Сделанное — в git и PR, закрытое удаляется; правил здесь нет.
- `xray-dpi/references/lessons.md` — выжимка, одна строка на урок; полный разбор —
  `lessons-detail.md`. Выжимку читают в каждой задаче: строка, которая разрослась, — в разбор.

## Формат скилла (стандарт Agent Skills)

- Фронтматтер: `name` (= имя каталога; a-z, 0-9, дефис) и `description`. Другие поля — только
  если нужны и их понимают все агенты, которыми пользуются.
- `description` ≤ 1024 символов, от третьего лица: что делает и когда применять, словами,
  которыми пишет владелец (по-русски, ключевые термины и по-английски). Чуть «навязчивее»,
  чем кажется нужным: несработавший скилл обходится дороже лишнего срабатывания.
- Пути — относительные, через `/`. Справочник длиннее 100 строк начинается с оглавления.
- `evals/evals.json` — сценарии ожидаемого поведения (формат skill-creator); в контекст не грузятся.

## Содержание

- Один факт — в одном месте, в остальных — ссылка: копии расходятся молча.
- `SKILL.md` и правила — без дат и номеров версий, только то, что не устаревает. Всё
  датированное (версии Xray, поведение ТСПУ, пороги, клиенты) — в
  `xray-dpi/references/landscape.md`, по его разделу «Как обновлять».
- Писать, что делать и почему; общеизвестное не пересказывать — каждая строка скилла стоит
  контекста на каждом ходу, пока он загружен.
- Данных установки нет и здесь (AGENTS.md).

## Проверка после правки

- Фронтматтер парсится, `name` совпадает с каталогом, `description` ≤ 1024 символов.
- Все упомянутые пути существуют; двух правил, противоречащих друг другу, нет.
- Поведение скилла изменилось — поправить или добавить сценарий в `evals/evals.json`.
- В Claude Code `/doctor prompt-audit` ищет противоречия и мёртвые ссылки.
