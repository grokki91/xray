# Уроки прошлых разборов — выжимка

Ошибки и ложные выводы, которые уже случались в проекте, — одна строка на урок, без данных
установки. Сверяться до того, как предлагать код, диагностику или гипотезу; отдельно от
`sudo xm journal` — там детали конкретного сервера (`SKILL.md`, «Что уже разбирали»).

Тема задачи совпала с уроком — прочитать его полный разбор в `lessons-detail.md`: жирные
слова строки входят в заголовок записи там. Новый урок — строка сюда и разбор «Симптом →
Причина → Правило» туда, в той же правке. Вывод про конкретный сервер (порт, домен, адрес,
цифры) — в `xm journal`, не сюда.

## Вердикты диагностики

- **Критичное, которое нечем закрыть** — «критично» только для того, что пользователь может
  исправить и что меняет исход; неустранимое — предупреждение с названной ценой. Градаций,
  которых нет у проверяющего, не выдумывать.
- **Итоговый вердикт не учитывал часть проверок** — новый блок диагностики проверять по
  итоговой сводке, а не по его строке: счётчик должен жить там, где считается итог.
- **Два похожих счётчика** — разные причины (переполнение очереди и отказ до неё) — разные
  строки и разные подсказки.
- **«всё, кроме X»** — ветка `*)` называет значение и команду проверки, но не утверждает
  его последствий.
- **Накопительный счётчик** — вердикт по дельте с контрольной точки, итог за жизнь
  процесса — справочно; точку сбрасывать явной командой.

## Факт, а не догадка

- **Предположение о состоянии сервера** — сначала команда, показывающая состояние, и её
  вывод, потом рассуждение.
- **Значение в конфиге принято за состояние работающего сокета** — параметры, взятые при
  `listen()` (backlog и подобные), проверять на сокете той же выборкой, что диагностика;
  `reload` сокеты не пересоздаёт, успех — по перепроверке после `restart`.
- **Признак брался из конфига** — где следствие наблюдаемо (ответ, время, код), признак —
  наблюдение у клиента или зонда, а не поле конфига.
- **«Уже настроено — пропускаю»** — свой артефакт опознавать по содержимому, а не по пути;
  читать эффективную конфигурацию (main + все drop-in).
- **Возможность «объявлена»** — правка, опирающаяся на модуль или пакет, ставит его и
  перезапускает сервис; диагностика называет отсутствие модуля причиной.
- **Детектор состояния разбирал человекочитаемый вывод** — вывод CLI не API: шаблон сверять со
  всеми поддерживаемыми версиями ОС; «не разобрал» ≠ «выключено»; сначала следствие, потом
  разбор; внешняя причина отказа — гипотеза с командой проверки.
- **Обновлятор тянул текущую ветку чекаута** — сверять чекаут с веткой по умолчанию на origin
  и называть отставание; что на сервере новый код — по признаку из него, а не по «обновилось».
- **Имя списка geosite** — список под block/direct раскрывать по исходнику со всеми
  `include:`; «сервис в РФ» — признак адреса (`geoip:ru`), а не зоны имени.
- **Список риска брался у установленной версии** — то, что upstream ведёт списком, сверять с
  актуальным исходником, включая pre-release; копия — нижняя граница с версией; порог до
  установки — по тому, что поставит установщик (Latest).

## Сеть и доступность

- **Зонд с самого VPS не видит правила файрвола** — доступность снаружи проверять с клиента
  или внешней точки: с VPS запрос идёт через `lo` мимо ufw.
- **Публичный порт фронта и порт inbound** — новый публичный порт — отдельный шаг «открыть
  файрвол»; проверять правило, а не факт LISTEN.
- **Лимит соединений задан, а лимит дескрипторов — нет** — любой лимит «сколько
  одновременно» — в паре с `LimitNOFILE`/`ulimit` процесса.
- **Тест через SOCKS зелёный** — `curl --noproxy ''`; зелёный результат через прокси
  подтверждать соединением в логе сервера.

## Протокол и замеры

- **Сертификат, найденный на адресе** — кандидата, отобранного по сертификату, проверять
  резолвом имени в нужный диапазон; свой адрес исключать (dest на себя — петля).
- **Порог выведен из модели протокола** — порог — из исходника версии на сервере, по
  возможности тем же кодом; без этого не двигать.
- **Замер пути включал резолв имени** — резолвить один раз до цикла и мерить соединение с
  адресом; сбои резолва — отдельной строкой.
- **Отпечаток оценивался по имени пресета** — по ClientHello (группы key_share и их порядок)
  из ядра той версии, что у клиента; имя пресета — только ссылка на таблицу uTLS.
- **Молчаливый режим приватности** — при равной приватности выбирать режим, который отвечает;
  прежде чем считать выбор исчерпанным, проверить, какие значения принимает сборка.
